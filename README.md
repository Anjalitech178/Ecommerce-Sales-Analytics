# E-commerce Sales Analytics

An e-commerce data analytics project using Python, SQL, and Power BI to analyze sales, profit, and business trends.

## Tools Used
- Python (Pandas)
- MySQL
- Power BI
- Excel

## Key Features
- Sales and profit analysis
- Category-wise sales analysis
- Region-wise profit analysis
- Monthly sales trends
- Interactive Power BI dashboard

## Key Insights
- Technology had the highest sales.
- West region generated the highest profit.
- Consumer segment contributed the highest sales.

## Project Files
- `data/` – Datasets
- `outputs/` – Analysis results and charts
- `main.py` – Python analysis
- `check_data.py` – Data inspection
- `sales_analysis.sql` – SQL queries
- `Ecommerce_Sales_Analytics.pbix` – Power BI dashboard
